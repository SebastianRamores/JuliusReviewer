IMPORTANT SYNTAX

for (int i = 1; i <= 5; i++) { ... }
cout << "text" << endl;

STEP-BY-STEP EXPLANATION

  1. The for loop starts with i = 1.
  2. It checks "is i <= 5?"
  3. If yes, it runs the body: print "Hello!".
  4. It adds 1 to i.
  5. It goes back to step 2 and repeats.
  6. When i becomes 6, the condition is false and the loop stops.
  7. So the body runs 5 times: i = 1, 2, 3, 4, 5.
  8. ============================================================

Exam questions

How many times does the loop body run?
Answer: 5
What is the value of i when the loop ends?
Answer: 6
What if the condition were i < 5 instead?
Answer: body runs 4 times
What if the update were i += 2?
Answer: i = 1,3,5 -> 3 times
What if the update were i--?
Answer: INFINITE LOOP (see 12_common_mistakes)
