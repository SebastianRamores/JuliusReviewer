Print the Odd Numbers from 1 to 20

Beginner for loops + modulo, and the `!=` operator 121 lines 4 kb
Reading tip. Every grey note below is a collapsible explanation. Click its header to read it, or press C to hide every comment at once so the program logic stands on its own.

WHAT THIS PROGRAM TEACHES

  • The definition of an odd number.
  • Two correct ways to test for odd, and why both work.
  • The != (not equal to) operator.

IMPORTANT SYNTAX

if (i % 2 != 0) { ... }      // remainder is NOT zero  -> odd
if (i % 2 == 1) { ... }      // remainder is exactly 1 -> odd

STEP-BY-STEP EXPLANATION

Visit every number 1..20. For each one ask: "does dividing by 2 leave a
remainder?" If something is left over, the number is odd, so print it.
20 is even, so the last odd printed is 19.

Exam questions

How many odd numbers in 1..20?
Answer: 10
What does 9 % 3 equal?
Answer: 0 (9 is divisible by 3)
Write the condition "i is divisible by 3".
Answer: i % 3 == 0
Write the condition "i is divisible by both 2 and 5".
Answer: i % 2 == 0 && i % 5 == 0
Rewrite using i % 2 == 1.
Answer: identical output
