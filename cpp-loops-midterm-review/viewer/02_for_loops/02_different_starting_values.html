Different Starting Values in a for Loop

Beginner for loops - the initialization part 253 lines 10 kb
Reading tip. Every grey note below is a collapsible explanation. Click its header to read it, or press C to hide every comment at once so the program logic stands on its own.

WHAT THIS PROGRAM TEACHES

  • The FIRST part of the header is called the initialization.
  • Changing only the start value changes BOTH the first printed number
  • Three identical loops that differ in one character.
  • How to read a loop header backwards to check your work.

STEP-BY-STEP EXPLANATION

  1. The three loops below are identical except for the number in the
  2. initialization part of the header.
  3. Loop 1 starts at 1 and stops after 5 -> prints 1,2,3,4,5 (5 values).
  4. Loop 2 starts at 0 and stops after 5 -> prints 0,1,2,3,4,5 (6 values).
  5. One extra value, because 0 was added in front of the old list.
  6. Loop 3 starts at 5 and stops after 10 -> prints 5,6,7,8,9,10 (6 values).
  7. Same count as loop 2: the window 0..5 and the window 5..10 are both
  8. six numbers wide.
  9. CONCLUSION: the start value decides the FIRST number printed, and it
  10. also decides how many numbers there are.
  11. ============================================================

THE 10-SECOND EXAM METHOD

Write the sequence of values on paper BEFORE you answer. If you
cannot list the values, you do not yet understand the loop.
Then count the entries in your list - that is the iteration count.

THE COMMON TRAP IN THIS FILE

Counting by looking at the LIMIT only. `i <= 5` never tells you the
count on its own - it depends on the start value too. Reading a
header backwards (update, then condition, then start) is the habit
that stops this mistake.

Exam questions

How many values does for (int i = 1; i <= 5; i++) print?
Answer: 5
How many values does for (int i = 0; i <= 5; i++) print?
Answer: 6
What is the difference between the two counts?
Answer: the start value moved from 1 down to 0, adding one extra value at the front
What is printed on the very first line of loop 3?
Answer: 5
If loop 3 started at 5 but stopped at i < 10, how many values?
Answer: 5 (prints 5 6 7 8 9)
Why must the limit be changed in loop 3?
Answer: otherwise the loop would print only 5 and stop on the second test
